# JobNest Privacy Policy

JobNest is a local job application tracker browser extension.

## Data JobNest Stores

JobNest stores job application information that you enter, including:

- Company name
- Role/title
- Job URL
- Location
- Application status
- Status dates
- Notes

JobNest also stores a temporary popup draft so unfinished form text is not lost when the popup closes.

## Where Data Is Stored

JobNest stores data locally in your browser using Chrome extension storage.

If you choose a backup file, JobNest also writes your application data to the local JSON backup file that you selected on your own device.

## Data Collection

JobNest does not collect, transmit, sell, or share your job application data.

JobNest does not send your data to any external server.

## Permissions

JobNest requests:

- `storage`: used to save your job applications and popup drafts locally in your browser.
- `activeTab`: used to prefill the current tab URL and page title when you save a job from the popup.

## Contact

For support or privacy questions, contact the extension publisher through the Chrome Web Store listing.
